Confidentialité

Politique de confidentialité

Cette politique décrit la manière dont l’extension Chrome ScanYTB — YouTube Link Scanner traite les informations lorsqu’elle est utilisée sur YouTube.

En bref : l’extension analyse localement la page YouTube ouverte afin d’identifier les liens et domaines visibles dans la description. Elle ne transmet pas automatiquement le contenu analysé aux serveurs de ScanYTB.

1. Fonctionnement de l’extension

ScanYTB analyse la page YouTube actuellement consultée afin d’identifier les liens et noms de domaine présents dans la description d’une vidéo, ainsi que certaines informations publiques liées à la vidéo ou à la chaîne.

Cette analyse permet à l’utilisateur d’identifier rapidement les outils, sites, sponsors, réseaux sociaux et autres liens mentionnés dans les contenus YouTube.

2. Données consultées

Lorsque l’utilisateur ouvre l’extension sur YouTube, ScanYTB peut lire les informations publiques de la page concernée, notamment :

  • le titre de la vidéo ;
  • le nom de la chaîne YouTube ;
  • l’URL publique de la vidéo ou de la chaîne ;
  • l’image publique de la chaîne lorsqu’elle est disponible ;
  • le texte de la description de la vidéo ;
  • les liens hypertextes et noms de domaine présents dans cette description.

ScanYTB n’accède pas aux mots de passe, e-mails, messages privés, moyens de paiement ou autres données privées du compte Google de l’utilisateur.

3. Traitement local

Les informations présentes sur la page YouTube sont analysées localement dans le navigateur afin d’afficher les liens et domaines détectés dans l’interface de l’extension.

L’extension ne transmet pas automatiquement le contenu des pages YouTube consultées vers les serveurs de ScanYTB.

4. Ouverture de ScanYTB

Certaines fonctionnalités permettent à l’utilisateur d’ouvrir volontairement scan-ytb.com afin d’effectuer une recherche ou une analyse complémentaire.

Cette action est déclenchée uniquement lorsque l’utilisateur clique volontairement sur un bouton de l’extension. Des informations publiques telles qu’un nom de chaîne ou un nom de domaine peuvent être ajoutées à l’URL afin de préremplir la recherche sur ScanYTB.

5. Données personnelles

L’extension ScanYTB ne collecte pas directement d’informations permettant d’identifier personnellement l’utilisateur.

Elle ne collecte notamment pas le nom, l’adresse e-mail, l’adresse postale, les mots de passe, les données bancaires, les données de santé, les communications privées ou la position GPS de l’utilisateur.

6. Historique de navigation

ScanYTB n’a pas pour objectif de suivre l’historique de navigation de l’utilisateur. L’extension fonctionne uniquement sur les pages YouTube auxquelles elle est autorisée à accéder afin de fournir sa fonctionnalité principale.

7. Vente et partage des données

ScanYTB ne vend pas les données des utilisateurs.

Les informations traitées par l’extension ne sont pas utilisées à des fins publicitaires, de profilage, de détermination de solvabilité ou de prêt, et ne sont pas transférées à des tiers à des fins sans rapport avec la fonctionnalité principale de l’extension.

8. Code distant

L’extension n’exécute pas de code JavaScript ou WebAssembly distant. Le code nécessaire à son fonctionnement est inclus dans le package distribué via le Chrome Web Store.

9. Sécurité et permissions

Nous limitons les permissions de l’extension aux fonctionnalités nécessaires à son fonctionnement et cherchons à minimiser les données auxquelles elle accède.

10. Modifications de cette politique

Cette politique de confidentialité peut être mise à jour si les fonctionnalités de ScanYTB évoluent. La version disponible sur cette page constitue la version actuellement applicable.

11. Contact

Pour toute question concernant cette politique ou l’extension ScanYTB, contacte-nous depuis scan-ytb.com.
